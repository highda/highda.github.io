Font Ripper

A bookmarklet that finds every font on a page — CSS, JS FontFace, type testers, even styles the tester hasn't loaded yet — with live previews and one-click ZIP download.

Install

  1. Show the bookmarks bar (Ctrl/⌘ + Shift + B).
  2. Drag the Font Ripper button onto it.
  3. Open any page and click the bookmark.

Can't drag (mobile, some browsers)? Hit “Copy code”, create a new bookmark and paste it as the URL.

What it catches

  • CSS @font-face incl. @import, shadow DOM, same-origin iframes and CORS-blocked sheets
  • Fonts registered from JS via FontFace, matched to their files by glyph metrics + internal names
  • Any font file the page downloaded, even from extension-less URLs
  • Font files referenced in the page source that haven't been loaded yet

Out of reach: cross-origin iframes (listed so you can run it there), fonts decrypted in JS, text rendered into images.
