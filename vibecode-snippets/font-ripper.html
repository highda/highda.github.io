Tech specs.

Installation
  1. Show the bookmarks bar (Ctrl/⌘ + Shift + B).
  2. Drag the Font Ripper button onto it.
  3. Open any page and click the bookmark.

Can't drag (mobile, some browsers)? Use “Copy code”, create a new bookmark and paste it as the URL.

Detects
  • CSS @font-face rules, including @import, shadow DOM, same-origin iframes and CORS-blocked sheets
  • Fonts registered from JavaScript via FontFace, matched to their files by glyph metrics and internal names
  • Any font file the page downloaded, even from extension-less URLs
  • Font files referenced in the page source that haven't been loaded yet
Output
Live previews of every face, individual downloads, or everything as a single ZIP.
Limitations
Cross-origin iframes (listed so you can run it there), fonts decrypted in JavaScript, and text rendered into images.
Updates
The button always installs the latest build from the source repository.
  1. Please respect font licences. Font Ripper finds files; what you do with them is between you and the foundry.
